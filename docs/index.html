Bref

Notes that open before you blink.

A fast, minimal note-taking app. Notes are plain Markdown files in a folder you choose, styled as you type. Written in Rust with GPUI, the framework behind Zed.

#markdown#rust#linux#macos#windows

Features

  • Opens instantly: the window is on screen in about 75 ms.
  • Plain files: one .md per note. Sync with git or Syncthing; an Obsidian vault works as is.
  • Styled as you type: headings grow, markers stay visible but dimmed. The file is always plain Markdown.
  • Slash commands: / inserts a heading, list, panel, code block, formula, or a table sized on a grid.
  • Links and graph: [[links]], #tags, renames that rewrite your links, and a graph of your notes.
  • Diagrams: Mermaid, LaTeX, or shapes and arrows drawn on a canvas, saved as SVG in your vault.
  • Keyboard first: one palette to find, create and switch. No toolbar, no save button.
  • Yours to dress: a dozen themes, any installed font. English and French.

Install

Arch Linux

A prebuilt package ships with every release. No compiler needed.

curl -LO https://github.com/alarboulletmarin/bref/releases/latest/download/bref-x86_64.pkg.tar.zst
sudo pacman -U ./bref-x86_64.pkg.tar.zst

macOS, Windows, other Linux

Bref is compiled on your machine, with a recent Rust (1.88 or later).

git clone https://github.com/alarboulletmarin/bref.git
cd bref
cargo install --path . --locked
[!NOTE]Linux needs a few system libraries and a Vulkan driver, macOS needs Xcode, Windows the Visual Studio C++ tools. There is no .app or installer yet. Steps for each system.

Documentation

On first run Bref asks for a vault, the folder that holds your notes. That is the only setup. The essentials, Cmd instead of Ctrl on macOS:

| Key                | Action                                         |
| ------------------ | ---------------------------------------------- |
| Ctrl + P           | palette: find or create a note, filter by #tag |
| Ctrl + N           | new note                                       |
| /                  | insert a heading, list, panel, code or table   |
| Ctrl + E R G T     | tree, recent, graph, tags                      |
| Ctrl + Shift + D   | new diagram                                    |
| Ctrl + K, Ctrl + T | theme                                          |
| F1                 | every shortcut, inside the app                 |

The README covers the rest: shortcuts navigation markdown diagrams vault troubleshooting
