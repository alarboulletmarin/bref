Features

Everything to write. Nothing in the way.

One window, one palette, one folder of files. The rest stays out of sight until you need it.

# Trip to Lisbon
Three days in **May**, see [[Budget]]
- [x] Flights
- [ ] Hotel near Alfama

Styled as you type

Headings grow, bold and links render, the markers stay visible but dimmed. The file is always plain Markdown.

Plain files, your folder

One .md per note. Sync with git, Syncthing, iCloud or Dropbox. An existing folder of notes works as is.

One palette finds notes by name or text, creates, switches and runs every command. No toolbar, no save button.

Tables like on the web: paste from a page or a spreadsheet, wrap in cells, and start a cell with = to compute. The file keeps the formula.

Writing

  • Slash commands and a formatting bar
  • Blocks you can drag, with a menu
  • Templates and a daily note
  • Find, replace and several cursors
  • Comments kept as CriticMarkup

Organizing

  • Embedded sections of other notes
  • Kanban boards in plain Markdown
  • A folder or a tag shown as a table
  • Two panes, back and forward
  • CSV and TSV opened in a grid

The app

  • Sync a git vault in one action
  • A dozen readable themes, light and dark
  • English and French
  • Trash you can undo, backup in one command
  • Updates itself, if you let it
Install

Ready in a minute.

On first run, one click creates your vault in Documents/Notes, or open any folder of Markdown notes. That is the only setup.

Windows

Windows 10 or 11, 64-bit. No administrator rights needed. If SmartScreen warns, click More info, then Run anyway.

Download installer

macOS

Apple Silicon and Intel, macOS 11 or later. Not notarized: the first launch needs Open Anyway in Privacy & Security.

Download .dmg

Arch Linux

A prebuilt package ships with every release.

curl -LO https://github.com/alarboulletmarin/bref/releases/latest/download/bref-x86_64.pkg.tar.zst
sudo pacman -U ./bref-x86_64.pkg.tar.zst

Other Linux

Compiled on your machine with Rust 1.88 or later.

git clone https://github.com/alarboulletmarin/bref.git
cd bref
cargo install --path . --locked

Linux needs a few system libraries and a Vulkan driver: steps for each system. Bref tells you when a new version is out, and on Windows, macOS and Arch one click updates it.
